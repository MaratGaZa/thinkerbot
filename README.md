# ThinkerBot — Telegram-бот с локальной LLM

Это Telegram-бот, который принимает текстовые сообщения, отправляет их в локальную LLM (Ollama) и возвращает ответ пользователю.

## ⚙️ Требования

Для работы проекта необходимы:
- Python 3.12+
- Ollama с установленными моделями: `qwen2.5:3b`, `qwen3.5:0.8b`, `qwen3.5:2b`, `qwen3.5:4b`, `gpt-oss:20b`.
- Токен Telegram Bot.

## 🚀 Установка и Настройка

### 1. Установка зависимостей
Вы можете использовать `uv` (рекомендуется) или `pip`.

```bash
# Через uv (рекомендуется)
uv pip install -e ".[test]"

# Или через pip
pip install -r requirements.txt
```

### 2. Настройка окружения
Создайте файл `.env` в корне проекта:
```bash
cp .env.example .env
```
Отредактируйте `.env` и укажите ваши параметры:
```env
TEL_BOT_TOK=ваш_токен_telegram_бота
OLLAMA_URL=http://localhost:11434
MODEL_NAME=qwen3.5:4b
TIMEOUT=30
```

### 3. Получение токена Telegram Bot
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/newbot`.
3. Следуйте инструкциям для создания бота.
4. Скопируйте полученный токен в `.env`.

### 4. Установка Ollama и моделей
Выполните следующие шаги для настройки среды LLM:

```bash
# Установка Ollama (macOS/Linux)
curl -fsSL https://ollama.com/install.sh | sh

# Запуск сервера Ollama (должен работать в фоне!)
ollama serve
```

**Установка моделей (Рекомендовано начать с легкой модели):**
```bash
ollama pull qwen2.5:3b       # модель по умолчанию (легкая)
ollama pull qwen3.5:0.8b     # самая легкая
ollama pull qwen3.5:2b       # легкая
ollama pull qwen3.5:4b       # средняя
ollama pull gpt-oss:20b      # тяжелая (требует мощный GPU)
```

## 🛠️ Запуск бота

Для запуска бота выполните команду:

```bash
.venv/bin/python -m app.main
```

## ✨ Использование Бота

1. **Запустите бота** и убедитесь, что он слушает входящие сообщения.
2. **Отправьте текстовое сообщение** в Telegram.
3. Бот автоматически обработает запрос через LLM и вернет вам ответ.

### 🤖 Команды и Модели

- `/model` — команда для выбора модели.

**Доступные модели:**
- `qwen2.5:3b` — по умолчанию (рекомендуется)
- `qwen3.5:0.8b` — самая легкая и быстрая
- `qwen3.5:2b` — легкая
- `qwen3.5:4b` — средняя
- `gpt-oss:20b` — тяжелая (требует мощный GPU)

## 🏛️ Архитектура Системы

Структура проекта:
```
app/
├── main.py                 # Точка входа, обработчик запросов (polling)
├── core/
│   ├── config.py           # Конфигурация окружения (.env)
│   ├── errors.py           # Кастомные исключения
│   └── logger.py           # Структурированное логирование
├── handlers/
│   └── message_handler.py  # Логика обработки сообщений Telegram
├── services/
│   └── llm_service.py      # Основной сервис взаимодействия с LLM
└── clients/
    └── ollama_client.py    # HTTP клиент для API Ollama
```

## ⚠️ Обработка ошибок
| Сценарий | Ответ бота |
|----------|------------|
| LLM недоступна | "LLM is unavailable" |
| Таймаут | "Request timeout" |
| Получен пустой ответ | "Empty response" |
| Внутренняя ошибка | "Internal error" |

## 📝 Основные Особенности
*   Обрабатывает только текстовые сообщения (фото, видео, файлы игнорируются).
*   Использует асинхронную обработку запросов.
*   **Важно:** Не хранит историю диалогов и не использует базу данных.
*   Работает по принципу polling (а не webhook).
