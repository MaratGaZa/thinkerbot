# ThinkerBot — Telegram-бот с локальной LLM

Это Telegram-бот, который обрабатывает текстовые сообщения, поддерживает **сохранение истории чата** и **управление контекстом** с помощью локальной LLM (Ollama).

## ⚙️ Обзор системы и архитектура

Система построена на принципах **Stateful (сохраняющего состояния)** взаимодействия, что позволяет боту вести долгие диалоги, помнить предыдущие сообщения и использовать механизм суммаризации (сжатия контекста) для эффективной работы с лимитами токенов.

## 🚀 Требования

Для работы проекта необходимы:
- Python 3.12+
- Ollama (локальный LLM runtime)

## � Установка и настройка

### 1. Клонирование и установка зависимостей

Вы можете использовать `uv` (рекомендуется) или `pip`:

```bash
# Через uv (рекомендуется)
uv pip install -e ".[test]"

# Или через pip
pip install -r requirements.txt
```

### 2. Настройка окружения

Создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
```

Отредактируйте `.env` и укажите ваши параметры:

```env
# Обязательные параметры
TEL_BOT_TOK=ваш_токен_telegram_бота
OLLAMA_URL=http://localhost:11434
MODEL_NAME=qwen2.5:3b

# Таймаут для генерации ответа LLM (секунды)
TIMEOUT_READ=180

# Настройки истории чата
ENABLE_HISTORY=true
HISTORY_MAX_MESSAGES=20
HISTORY_MAX_TOKENS=2000
HISTORY_SUMMARIZE_TRIGGER=5
```

### 3. Получение токена Telegram Bot

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `.env`

### 4. Установка Ollama и моделей

Выполните следующие шаги для настройки среды LLM:

```bash
# Установка Ollama (macOS/Linux)
curl -fsSL https://ollama.com/install.sh | sh

# Запуск сервера Ollama (должен работать в фоне!)
ollama serve
```

**Установка моделей (рекомендуется начать с легкой модели):**

```bash
ollama pull qwen2.5:3b       # модель по умолчанию (лёгкая)
ollama pull qwen3.5:0.8b     # самая лёгкая и быстрая
ollama pull qwen3.5:2b       # лёгкая
ollama pull qwen3.5:4b       # средняя
ollama pull gpt-oss:20b      # тяжёлая (требует мощный GPU)
```

## 🛠️ Запуск бота

Для запуска бота выполните команду:

```bash
.venv/bin/python -m app.main
```

## ✨ Использование бота

### Команды бота

- `/start` — Запустить бота и показать приветственное сообщение
- `/help` — Показать информацию о боте
- `/model` — Выбрать модель для обработки
- `/sys <текст>` — Изменить системный промпт (поведение бота)
- `/sysreset` — Сбросить системный промпт к умолчанию

### Доступные модели

- **турба** (qwen2.5:3b) — быстрая, для простых задач
- **турба версия 2** (qwen3.5:0.8b) — самая лёгкая и быстрая
- **оптимальная** (qwen3.5:2b) — баланс скорости и качества
- **точная** (qwen3.5:4b) — более точные ответы
- **умная** (gpt-oss:20b) — самая умная, но медленная

### Структура проекта

```
app/
├── main.py                      # Точка входа, настройка polling
├── core/
│   ├── config.py                # Конфигурация окружения (.env)

│   ├── logger.py                # Структурированное логирование
│   └── system_prompt.py         # Провайдер системного промпта
├── clients/
│   └── ollama_client.py         # HTTP клиент для API Ollama
├── services/
│   └── llm_service.py           # Сервис взаимодействия с LLM, логирование контекста
├── handlers/
│   └── message_handler.py       # Обработчики сообщений Telegram
├── history/
│   └── history_manager.py       # Управление историей чата
└── img/
```

### Поток обработки запроса

```
Telegram User → Telegram API → aiogram (polling) → main.py
                                                      ↓
                                              Dispatcher routes
                                                      ↓
                                              MessageHandler
                                                      ↓
                                              HistoryManager
                                                      ↓
                                              LLMService
                                                      ↓
                                              OllamaClient
                                                      ↓
                                              Ollama API (localhost:11434)
```

## 📝 Основные особенности

### Управление историей чата

- **Per-user storage**: История хранится отдельно для каждого пользователя в памяти
- **Автоматическая суммаризация**: Когда история превышает лимит, старые сообщения суммируются LLM
- **Лимиты**: Настраиваются через переменные окружения (`HISTORY_MAX_MESSAGES`, `HISTORY_MAX_TOKENS`)
- **Системный промпт**: Всегда добавляется в начало контекста и никогда не удаляется

### Логирование

- Все контексты, отправленные в LLM, логируются в `logs/context.log`
- Формат: JSON с timestamp, user_id, количеством сообщений и токенов
- Полезно для отладки и аудита

### Обработка ошибок

| Сценарий | Ответ бота |
|----------|------------|
| LLM недоступна | "LLM is unavailable" |
| Таймаут | "Request timeout" |
| Получен пустой ответ | "Empty response" |
| Внутренняя ошибка | "Internal error" |

### Другие особенности

- Обрабатывает только текстовые сообщения (фото, видео, файлы игнорируются)
- Использует асинхронную обработку запросов
- Работает по принципу polling (а не webhook)
- История хранится в памяти и теряется при перезапуске бота
- Поддерживает выбор модели во время работы бота
