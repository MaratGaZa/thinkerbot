## Промпт 9: Исправление лимита сообщений Telegram

```
1. Ошибка №1 — message is too long
TelegramBadRequest: message is too long
👉 Это ограничение Telegram, а не твоего кода.

❗ Лимит:
    •    максимум 4096 символов в одном сообщении
✅ Решение — разбивать ответ
Добавь утилиту:
def split_text(text: str, max_length: int = 4000) -> list[str]:
    return [text[i:i + max_length] for i in range(0, len(text), max_length)]

🔥 И используй так:
for part in parts:
    await message.answer(part)

✅ Решение (обязательно)

1. Ограничь max_tokens

Добавь в payload:
payload = {
    "model": self.model,
    "messages": [...],
    "stream": False,
    "options": {
        "num_predict": 512
    }
}
```

**Результат:**
- Добавлена утилита `split_text()`
- Ответы разбиваются на части по 4000 символов
- Добавлен `num_predict: 512` (позже изменён)
